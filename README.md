# 旅行照片风格化

上传一张旅行原照，选定风格后制作成片。内置五种配方：明亮手绘动画、可爱方块像素、复古 3D 游戏、半实拍旅行手账和旅行观察图鉴。

- [SKILL.md](SKILL.md) 是入口，定义推荐、确认和出图流程。
- [references](references/) 包含制作配方和验收标准。
- [scripts](scripts/) 包含旅行观察图鉴的 PNG 排版脚本，需要 Python、Pillow 和支持图注语言的字体。

使用时，把 Skill 文件夹导入支持该结构的客户端，或在试用聊天中上传 SKILL.md、相关参考说明和自己的原照，再说“看看这张照片适合什么风格，等我选好再制作”。具体出图能力取决于客户端提供的图像编辑和脚本运行工具。发布包只包含规则与脚本；运行时可另外上传自己的参考图。
