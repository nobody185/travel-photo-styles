# 旅行观察图鉴制作与验收

参考科研组图里的两种读法。野外调查图版用角标与下方图注逐一对应；旅行版保留这个读法，利用大图和小图建立主次，并把说明压成手机上能读完的短词。按主景、人物、动物、物件和环境细节选片，优先选画面内容互补的素材。照片只有一张时，给大图留全景，再选确实能提供新信息的局部。用户确认方向时用一句话说清主图和小图来源。

横向全景配两张局部用三面板。需要六幅时，默认用一个占两列两行的主面板、右侧两个小图和底部三个小图。给拍摄主体留边，角标避开人脸和主体。标题写地点或事件，地点不明时用用户确认的标题或中性描述。

准备 UTF-8 JSON，路径可相对清单，也可写绝对路径。每幅必须有 file 和 caption；crop 为归一化 [左, 上, 右, 下]；focus 为裁切对齐系数 [横, 纵]，从 0 到 1；需要保全照片时设置 contain 为 true。把主图放第一位。

```json
{
  "title": "图 1｜古镇散步",
  "panels": [
    {"file": "街景.jpg", "caption": "沿河街景"},
    {"file": "街景.jpg", "caption": "临河屋檐", "crop": [0.45, 0.05, 0.95, 0.5]}
  ]
}
```

用 Pillow 和支持图注语言的字体运行 scripts/render_observation_plate.py，传入清单路径、输出 PNG 路径和 --font 字体路径。Windows 中文可选系统自带的 msyh.ttc（如存在）。用预览检查 (a) 到末项依次对应，主图清楚，关键主体未被裁掉，文字完整且能在手机预览阅读。按需调整取景或图注后重新导出。
